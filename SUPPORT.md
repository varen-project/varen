# Getting Help

* Reach out to the project leads (Lead / Co-Lead) listed in the [Committers File]



## How to Ask for Help

If you have trouble installing, building, or using VAREN, but there's not yet reason to suspect you've encountered a genuine bug,
start by posting a question to the mailing list. This is the place for question such has "How do I...".
